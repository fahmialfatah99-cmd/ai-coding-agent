# 🌌 Alfa — Interactive Parallax Developer Portfolio & Repository Showcase

Website portofolio pribadi interaktif berdesain **Ultra-Modern Dark Theme & Parallax Effect** untuk memamerkan seluruh karya dan repositori open-source GitHub milik **Alfa** (@fahmialfatah99-cmd).

---

## ✨ Fitur Utama
1. **Multi-Layer Parallax & Glassmorphism Experience**:
   - Efek kedalaman parallax 3D pada cursor mouse dan scroll halaman.
   - Efek pantulan cahaya (*aurora glow & glassmorphism*) berbasis Tailwind CSS.
2. **Integrasi Dinamis GitHub API**:
   - Menarik data repositori publik secara real-time dari GitHub (@fahmialfatah99-cmd).
   - Dilengkapi dengan *fallback data* otomatis jika terjadi rate limit.
3. **Showcase Repositori Interaktif**:
   - 🔍 **Live Search**: Pencarian judul dan deskripsi repositori secara instan.
   - 🏷️ **Filter Bahasa Pemrograman**: Python, JavaScript, TypeScript, HTML/CSS, dsb.
   - 🌟 Menampilkan total bintang, fork, topik, dan link langsung ke repositori GitHub.
4. **Statistik & Aktivitas GitHub**:
   - Widget grafik statistik kontribusi dan top languages.
5. **100% Responsif & Mobile Friendly**:
   - Desain responsif sempurna untuk layar smartphone, tablet, laptop, dan monitor ultra-wide.
6. **Formulir Kontak Terintegrasi**:
   - Form pesan langsung terhubung ke email `fahmialfatah99@gmail.com`.
